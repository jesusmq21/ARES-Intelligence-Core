# ARES-Intelligence-Core

Núcleo de inteligencia operativa y automatización táctica para ciberseguridad. Sistema diseñado para centralizar el monitoreo de eventos, la gestión de logs y el soporte de decisiones en tiempo real dentro del ecosistema Umbrella SOC.

## Bitácora de Operaciones: Implementación A.R.E.S.
**Fecha:** 15 de junio de 2026
**Responsable:** Jesús Eduardo Machuca Quintero

### 1. Objetivo del Laboratorio
Desplegar y centralizar la inteligencia operativa de **A.R.E.S.** dentro del ecosistema "Cerebro de Umbrella", asegurando la capacidad de monitoreo de incidentes, automatización de scripts y visualización de datos.

### 2. Requerimientos de Hardware y Software
* **Hardware:** Laptop, Smart TV (Proyección de Centro de Comando).
* **Software:** Obsidian (Gestión de conocimiento), OBS Studio (Captura y producción), Python (Core de A.R.E.S.).

### 3. Pasos de Ejecución
* **Paso 1: Configuración de la Interfaz Visual**
  Se estableció la conexión inalámbrica para proyectar la terminal y el grafo de Obsidian en la Smart TV, creando un entorno de trabajo de alta disponibilidad.
* **Paso 2: Integración del Core A.R.E.S.**
  Se ejecutó el script principal (`ARES_CORE.py`) para inicializar el sistema de evaluación automática. Se realizaron pruebas de comandos de voz y texto para validar la respuesta del sistema.
* **Paso 3: Mapeo de Red Neuronal**
  Se organizaron los nodos en la vista gráfica de Obsidian para representar visualmente la arquitectura de inteligencia, conectando herramientas como Wazuh, Nmap y manuales de protocolos.
* **Paso 4: Captura de Operaciones**
  Se configuró OBS Studio para realizar la grabación de la demostración del sistema. Se estableció una tasa de bits (bitrate) de 2500 Kbps, optimizada para garantizar alta fidelidad técnica sin comprometer recursos de CPU.

### 4. Resultados Obtenidos
* Sistema A.R.E.S. operativo con latencia mínima en la ejecución de scripts.
* Documentación visual (Red Neuronal) consolidada y lista para auditoría técnica.
* Evidencia audiovisual generada para la presentación del portafolio.

### 5. Conclusión
El laboratorio fue exitoso. La integración entre el core de automatización y el sistema de gestión de conocimiento permite una respuesta táctica más rápida frente a las simulaciones de ataques del Umbrella SOC.
