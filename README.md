# ARES-Intelligence-Core

Núcleo de inteligencia operativa y automatización táctica para ciberseguridad. Sistema diseñado para centralizar el monitoreo de eventos, la gestión de logs y el soporte de decisiones en tiempo real dentro del ecosistema Umbrella SOC.
